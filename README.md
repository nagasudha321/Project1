# Food Delivery Data Warehouse using Snowflake

## 📌 Project Overview

This project demonstrates a simple **Food Delivery Data Warehouse using Snowflake**. CSV data is loaded into Snowflake tables and analyzed using SQL to generate useful business insights.

## 🛠️ Technologies

* Snowflake
* SQL
* CSV
* Internal Stage
* Snowflake Views

## 📊 Tables

* **CUSTOMERS** – Customer details
* **FOODITEMS** – Food item, price, category, and availability
* **ORDERS** – Order and transaction details

## 🔄 Process

```text
CSV Files → Internal Stage → Snowflake Tables → SQL Analysis → Reporting View
```

## 📈 Analysis Performed

* Total customer spending
* Top-spending customer
* Total revenue
* Revenue by food category
* Revenue by order status
* Top 3 customers
* Customer sales reporting using a view

## 🎯 Learning Outcome

This project demonstrates Snowflake warehouse creation, database/schema setup, CSV loading, SQL joins, aggregations, and creating views for reporting.
